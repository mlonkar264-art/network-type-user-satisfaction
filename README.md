
# Network Type and User Satisfaction Analysis

## About the Project
This is a C++ mini-project that studies the relationship between network type and user satisfaction.

It analyzes feedback from users of 4G, 5G and WiFi networks.

## Features
- Collects user data.
- Generates frequency distribution.
- Calculates percentage distribution.
- Performs Chi-Square Test of Independence.
- Displays statistical conclusions.

## Technologies Used
- C++
- GCC Compiler
- Visual Studio Code
- Statistics

## Statistical Method
Chi-Square Test of Independence.

- Significance Level: 0.05
- Degrees of Freedom: 4
- Critical Value: 9.488

## Network Categories
- 4G
- 5G
- WiFi

## Satisfaction Categories
- Satisfied
- Neutral
- Dissatisfied

## How to Run

Compile:
```bash
g++ main.cpp -o main.exe
```

Run:
```bash
./main.exe
```
